# 게임별 평가 파일

리포트 하단 `팀 평가` 에서 내려받은 CSV 를 이 폴더에 넣습니다.
파일 이름이 곧 게임입니다 — `Slotbound.csv` 는 `reports/global/Slotbound.html` 의 평가입니다.

```csv
평가자,완성도,차별화,적합성,검증,역량,확장성
창연,8,9,7,,6,8
민수,7,8,7,,5,7
```

`게임` 열이 없습니다. 파일 이름으로 구분하기 때문입니다.
판단할 근거가 없는 축은 비워 두세요 — 그 사람의 평균에서 빠집니다.

## 저장소 루트의 ratings.csv 와의 관계

두 곳을 모두 읽습니다.

- `ratings.csv` — `평가.html` 에서 23편을 한 번에 내려받은 일괄 파일
- `ratings/<슬러그>.csv` — 리포트에서 한 편씩 내려받은 파일

**같은 게임에 같은 사람이 양쪽에 있으면 이 폴더 쪽이 이깁니다.**
리포트에서 방금 매긴 점수가 예전 일괄 파일에 덮이지 않도록 하기 위해서입니다.
