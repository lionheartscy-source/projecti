01

핵심 요약

싱크홀 스튜디오는 2017년 설립된 성남 분당 소재의 초소형 인디 스튜디오(현재 약 4명)로, 어드벤처·시뮬레이션·카드/전략·모바일을 넘나드는 다장르·다플랫폼 개발이 특징입니다. 대표작 「오구와 비밀의 숲」은 인기 이모티콘 캐릭터 ‘아기 오구’(문랩스튜디오)의 IP를 게임화한 2D 어드벤처·퍼즐로, 텀블벅 펀딩·얼리액세스를 거쳐 PC·Nintendo Switch·모바일로 확장된 국산 인디 히트작입니다.

297개 맵·6개 지역의 볼륨과 ‘귀엽지만 빡센’ 난이도로 호평받았고, 부산인디커넥트(BIC)에서 IP 협업 성공 사례로 조명됐습니다. 다만 회사는 초소형·시드 단계이며 재무는 비공개로, 검증된 대표작·IP 협업 역량은 뚜렷하되 규모·자원 분산이 과제인 초기 스튜디오입니다.

스튜디오 특징

싱크홀 스튜디오는 소수 인원으로 어드벤처·시뮬·카드/전략·모바일을 두루 만드는 다장르 실험형 인디입니다. 대표작 오구는 외부 이모티콘 IP(‘아기 오구’)와의 협업으로 대중성을 확보한, 국내에서 손꼽히는 IP 컬래버 게임화 사례입니다.

  • PC·콘솔(Switch)·모바일까지 멀티플랫폼 대응력 보유
  • 텀블벅 펀딩·얼리액세스·분기 업데이트의 라이브 운영 경험
  • YouTube·Steam·SNS 등 활발한 커뮤니티 활동
포지셔닝 — ‘작지만 다재다능한’ 인디. 다만 초소형 규모에서 다장르를 병행해, 한 타이틀에 자원을 집중하기 어려운 구조적 한계가 함께 존재합니다.
03

대표작 분석 — 오구와 비밀의 숲

2D 어드벤처퍼즐전투IP 컬래버

인기 이모티콘 캐릭터 ‘아기 오구’가 잠든 소녀를 업고 비밀의 숲을 모험하는 2D 어드벤처. 297개 맵·6개 지역에 걸친 퍼즐과 전투가 핵심이며, ‘포켓몬 감성 + 벌레잡기’의 향수를 담았습니다.

이모티콘 IP 홀더(문랩스튜디오 문종범 대표)가 스프라이트 애니메이션을 직접 담당한 협업작으로, ‘귀엽지만 빡센’ 난이도가 정체성입니다. 3년 반 개발, 텀블벅 펀딩·얼리액세스를 거쳐 정식 출시했습니다.

  • 이모티콘 IP 기반의 친근한 캐릭터·대중성

유의점 — 정확한 판매량·리뷰 지표는 공개가 제한적입니다. 실제 평가·매출은 스팀/콘솔/모바일 실데이터 확인이 필요합니다.

투자 가능성 분석

강점 (Strengths)

  • 검증된 대표작(오구)·귀여운 IP 기반 대중성
  • 이모티콘 IP 컬래버·멀티플랫폼(스위치·모바일) 이식 역량
  • 다장르 개발·라이브 운영·텀블벅 펀딩 경험
  • 낮은 고정비(초소형)로 프로젝트당 손익분기 낮음

약점 (Weaknesses)

  • 약 4인 초소형 — 개발 여력·동시 프로젝트 제약
  • 다장르 분산으로 ‘간판 IP 집중’ 약함
  • 매출·투자·판매 지표 비공개(불투명)
  • 각 타이틀 규모가 작아 개별 매출 기여 제한

기회 (Opportunities)

  • 오구 IP 확장(후속작·굿즈·추가 DLC·글로벌)
  • 이모티콘·캐릭터 IP 컬래버 모델의 반복 적용
  • 히트 장르에 자원 집중 시 스케일업 여지
  • 콘솔·모바일 크로스 플랫폼 매출 다변화

위협 (Threats)

  • 인디 레드오션·플랫폼 노출 경쟁
  • 핵심 소수 인력 이탈 시 연속성 리스크
  • 다장르 분산이 ‘대표 IP 부재’로 이어질 위험
  • 자금·인력 제약에 따른 성장 속도 한계

싱크홀 스튜디오는 검증된 대표작과 IP 컬래버 역량을 갖춘 초기 스튜디오입니다. 오구의 성공·멀티플랫폼 이식은 실행력을 보여주지만, 초소형 규모·다장르 분산·재무 불투명이 리스크입니다.

투자 매력 요인
  • 대표작으로 제품·이식 실행력 검증
  • 재현 가능한 IP 컬래버 게임화 노하우
  • 낮은 고정비 → 소규모 자본으로도 성장 실험 가능
  • 오구 IP의 미디어믹스·후속작 업사이드
실사 시 필수 점검
  • 대표작·라인업별 판매·매출·순이익 실데이터
  • 시드 투자 조건·지분 구조·현금 런웨이
  • 오구 IP 권리 관계(문랩스튜디오와의 계약)
  • 차기작 파이프라인과 ‘집중 vs 다각화’ 전략
  • 핵심 인력 리텐션(초소형 팀 의존도)
투자 의견 — 검증된 대표작·IP 역량은 매력적이나 초소형·다장르 분산·재무 불투명을 감안한 ‘조건부 긍정’. 특히 오구 IP 집중·간판화 전략과 재무 실사가 투자 판단의 핵심입니다.
06

심화 분석 — 시장성 · 아트 · 메커니즘

① 장르·시장 포지션

싱크홀은 단일 장르가 아니라 여러 장르에 발을 걸친 구조라 하나의 TAM으로 논하기 어렵습니다. 대표작 오구(2D 어드벤처·퍼즐)는 대중성보다 매니아성이 강한 니치이나, 귀여운 캐릭터 IP로 대중 접점을 확보한 케이스입니다. 라인업 중 힐링/펫 시뮬(몰티즈)은 코지 대중 장르, 카드·로그라이크(3분 영웅·세컨드 세컨드)는 견고한 코어 장르에 속합니다.

결론 — 파이 크기는 장르마다 다르나, 이 스튜디오의 진짜 자산은 특정 장르 TAM보다 ‘귀여운 IP를 게임으로 만드는 역량’입니다. 캐릭터 IP는 굿즈·미디어믹스로 확장 가능한, 장르 TAM과 별개의 성장축입니다.
② 게임·회사 자체의 시장성

오구는 이모티콘 팬덤 → 게임 → 콘솔·모바일로 이어진 크로스 플랫폼 확장으로 시장성을 입증했습니다. 회사 차원에서는 ‘캐릭터 IP 컬래버 게임화’를 반복 가능한 공식으로 다듬을 수 있는지가 관건입니다. 다만 초소형·다장르 구조상 대표 IP에 자원을 집중하지 않으면 시장성이 분산될 수 있습니다.

  • 시장성 잠재형 — 검증된 IP + 멀티플랫폼 + 컬래버 노하우
  • 관건 — 간판 IP(오구) 집중·후속작으로 규모의 성장 증명
💰 미개척 수익원 — 1순위는 ‘IP 컬래버·캐릭터 사업’
이 스튜디오의 차별적 자산은 인기 캐릭터 IP를 게임화하는 역량입니다. 1순위 미개척 수익원은 ‘아기 오구’ 등 캐릭터 IP의 굿즈·미디어믹스와, 외부 이모티콘/캐릭터 IP 컬래버 게임을 반복 양산하는 모델입니다 — 이미 팬덤이 있는 IP를 쓰므로 마케팅비가 낮고 성공 확률이 높습니다. 2순위는 추가 DLC·후속작(겨울축제 대소동의 연장선)과 모바일·콘솔 크로스 판매. 단, 초소형 팀이라 ‘선택과 집중’이 전제입니다.
③ 아트 · 메커니즘 분석

🎨 아트

  • 인기 이모티콘 캐릭터 ‘아기 오구’ 기반의 친근한 도트/스프라이트 — 캐릭터 자체가 마케팅 자산
  • IP 원작자가 스프라이트 애니메이션을 직접 제작해 캐릭터 일관성·완성도 확보
  • 귀여운 톤이 SNS·굿즈 확산에 유리한 바이럴 후크

⚙️ 메커니즘

  • 297맵·6지역의 퍼즐 + 전투 결합, ‘귀엽지만 빡센’ 난이도가 정체성
  • 포트폴리오 전반에 카드·로그라이크·시뮬 등 다양한 시스템 실험
